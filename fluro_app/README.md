# 荧光浓度建模 APP（本地版）

仅供个人电脑本地使用的荧光试纸浓度建模工具：上传试纸照片，自动完成 **预处理 → ROI 分割 → 特征提取 → 浓度建模 → 浓度检测**，全程数据保存在本机，无需联网、无需登录。

## 快速开始

1. **双击 `start.bat`**（Windows）。首次会检查依赖并自动安装到项目内虚拟环境。
2. 浏览器自动打开 `http://127.0.0.1:8790`，即可使用。
3. 关闭窗口即停止服务；数据已落盘，下次启动数据仍在。

手动启动：

```bat
cd fluro_app
.venv\Scripts\python.exe server.py
```

> 端口冲突时自动改端口；可用环境变量 `FLURO_PORT=9000` 指定端口。

## 功能模块

| 模块 | 说明 |
| --- | --- |
| 首页总览 | 最近检测结果（C±U）、标定曲线状态、生效模型 R²、今日概览 |
| 检测工作流 | 批量上传（缩略图墙 + 流水线状态徽标）→ 预处理（暗场/平场/去噪 + 前后对比）→ ROI 自动套用 + 手动框选修正 → 特征提取（色相/比值/强度/纹理熵）→ 检测结果（C±U + 超限判定） |
| 标定建模 | 浓度分组、多浓度数据管理、4 类模型拟合（线性/二次/指数/4PL）对比 R²/RMSE/LOD、曲线可视化、模型保存/激活/历史 |
| 检测记录 | 按时间/批次/判定关键词检索、详情（模型参数快照）、导出 CSV |
| 数据与设置 | 判定上下限、单位、默认批次、ROI 模板管理、模型管理、参考图、一键备份与恢复 |

## 自动流水线

上传图片后自动依次执行：预处理（默认参数）→ ROI（用激活模板自动定位）→ 特征提取 → 结果（检测图用生效模型出 C±U）。任一步骤异常或需人工时，图片标记「需人工」，点击可进入该图逐步修正；修正上游后下游自动重算（级联）。

## 数据存储与备份

- 数据目录：`fluro_app\data\`（`fluro.db` 数据库 + `images\` 原图 + `thumbnails\` 缩略图 + `processed\` 处理图）。
- 备份：在「数据与设置」页一键备份，备份保存在 `fluro_app\backups\`，可随时恢复；恢复前会自动备份当前数据。
- 建议定期备份。

## 测试

```bat
cd fluro_app

```

测试覆盖：环境与启动冒烟、数据层与上传、预处理、ROI 与特征、自动流水线、标定建模、检测判定、记录检索与导出、设置与备份恢复、验收（持久化/性能/边界）。

## 使用提示

- 首次使用：先在「检测工作流」上传一张标定图 → 第 3 步框选检测区并「存为模板」；再到「标定建模」加入浓度分组、拟合、保存生效模型；之后上传检测图即可自动出结果。
- 高浓度端（偏红色）色相测量噪声较大，若标定曲线在红端拟合不佳，可在建模页改用「G/R 通道比」等比值特征。
- 合成测试图工具：`fluro_app\tools\make_test_images.py`，可批量生成已知浓度的模拟荧光图用于体验流程。
